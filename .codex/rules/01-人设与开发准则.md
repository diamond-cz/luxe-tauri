# 人设与开发准则

## 适用范围

适用于本仓库所有前端、Rust、脚本、配置和文档改动。规则目录为 D:\Image_process\luxe-tauri\.codex\rules；项目根目录为 D:\Image_process\luxe-tauri。

## 规则条目

### R01: 先确认现状

**断言**：修改前先检查 `git status --short`，再阅读相关入口、状态、IPC 和测试。必须保留已有未提交改动。

**示例**：

~~~powershell
git status --short
rg -n "saveImageTableMode|save_image_table_mode" src src-tauri/src
~~~

**违规特征**：未读现有代码就新建重复逻辑，或清除用户的未提交文件。

### R02: 限定改动边界

**断言**：代码放在负责该功能的目录。图片表格列设置放在 `src/views/mtk/isp6s/TablePane/`；跨页面复用逻辑才放入 `src/components/`、`src/services/` 或 `src/ipc/`。

**示例**：

~~~text
src/views/mtk/isp6s/TablePane/ColumnSettingsWindow.tsx
src/views/mtk/isp6s/TablePane/imageTableColumnSettings.ts
~~~

**违规特征**：为单个表格需求修改全局应用入口，或在视图文件中复制已有的 IPC 封装。

### R03: 交付验证结果

**断言**：交付时列出实际运行的命令、结果和未执行的验证。前端改动至少运行 `npm run typecheck`；Rust 行为改动运行 `npm run rust:test`。

**示例**：

~~~text
验证：npm run typecheck（通过）；npm run build（通过）。
限制：未在 Tauri 窗口中手动检查多显示器位置。
~~~

**违规特征**：未运行验证却声称已通过，或把编译通过写成桌面端交互已经验收。
