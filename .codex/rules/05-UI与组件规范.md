# UI 与组件规范

## 适用范围

适用于 D:\Image_process\luxe-tauri\src 下的 React 页面、Fluent UI 组件、Tailwind 样式及独立 Tauri 窗口。当前前端为 React 18.3.1、Fluent UI React Components 9.72.9 和 Tailwind CSS 3.4.19。

## 规则条目

### R01: 使用语义化主题令牌

**断言**：背景、文字、边框、悬浮和焦点颜色必须使用 Fluent 语义令牌或 `src/styles/globals.css` 的主题变量。新品牌色只放在 `src/theme/fluent-tokens.ts`。

**示例**：

~~~css
.column-settings-row {
  color: var(--colorNeutralForeground1);
  background: var(--colorNeutralBackground1);
  border-color: var(--colorNeutralStroke2);
}
.column-settings-row:hover {
  background: var(--colorNeutralBackground2);
}
~~~

**违规特征**：在单个组件里写固定的 #ffffff 背景，导致深色主题仍显示白底；悬浮色绕过主题令牌。

### R02: 沿用组件和图标入口

**断言**：按钮、输入、开关和标签页使用 `@fluentui/react-components`；图标从 `@fluentui/react-icons` 导入；图标按钮必须有 `aria-label` 或可见文字。

**示例**：

~~~tsx
import { Button } from "@fluentui/react-components";
import { Settings24Regular } from "@fluentui/react-icons";

<Button appearance="subtle" icon={<Settings24Regular />} aria-label="表格列设置" />;
~~~

**违规特征**：同一个界面混入另一个组件库的按钮，或只显示齿轮图标却没有可访问名称。

### R03: 窗口与表格布局可适配

**断言**：独立窗口必须检查最小尺寸、显示器位置、深浅主题和键盘焦点。表头和数据行必须共用列宽，出现滚动条后仍要对齐。

**示例**：

~~~css
.column-settings-grid {
  grid-template-columns: minmax(125px, 1fr) minmax(200px, 1.7fr) 68px 40px 56px;
}
~~~

**违规特征**：表头和行分别定义列宽，或窗口只在主显示器和默认主题下可用。

### R04: UI 回归使用实际窗口

**断言**：修改窗口打开、关闭、拖拽、滚动、主题或交互状态后，应在 Tauri 开发窗口核对相关动作；未能实测时，交付说明明确标记。UI PR 附实际截图。

**示例**：

~~~powershell
npm run tauri:dev
~~~

**违规特征**：仅运行 npm run build 就宣称多显示器定位、按钮动效或表格拖拽已经通过人工验收。

### R05: 所有表格共用颜色阈值

**断言**：AEGain、EV 和 CWR 差值只使用一套阈值；`All`、`Face`、`Normal` 不单独保存，Tone 模式继续读取 `All`。

**示例**：

~~~ts
const thresholds = imageTableSettings.color_thresholds;
~~~

**违规特征**：为各标签分别保存阈值，或给 Tone 增加另一套阈值。
