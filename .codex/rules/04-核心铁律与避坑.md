# 核心铁律与避坑

## 适用范围

适用于图片预览、解析缓存、观察器、后台任务、更新发布和改动验证。性能基线见 D:\Image_process\luxe-tauri\docs\performance\MEMORY_RECOVERY.md。

## 规则条目

### R01: 缓存必须有预算和清理入口

**断言**：新增图片或解析缓存时，必须在代码中定义容量或字节预算、淘汰条件，并接入现有 clear_memory_caches() 或对应 clear()；跨页面释放通过 src/ipc/memory.ts 的 trimMemory(true) 触发。

**示例**：

~~~ts
import { trimMemory } from "@/ipc/memory";

void trimMemory(true);
~~~

**违规特征**：把完整解码图片无限量放进 Map，或仅清空 React 状态却保留 Rust 缓存。

### R02: 异步结果不得覆盖新状态

**断言**：与当前文件、图片或页面绑定的异步请求，必须在依赖改变或卸载后忽略旧结果；ResizeObserver 只在测量值变化时更新 React 状态。

**示例**：

~~~tsx
useEffect(() => {
  let active = true;
  loadState().then((state) => {
    if (active) setState(state);
  });
  return () => { active = false; };
}, []);
~~~

**违规特征**：切换图片后旧请求仍写入新图片界面，或尺寸观察器每次回调都无条件 setState。

### R03: 密钥和发布产物不得入库

**断言**：不得提交 .tauri-updater.key、.tauri-updater.password、src-tauri/resources/state.toml、dist 或 src-tauri/target；更新签名公钥及端点变更须核对 src-tauri/tauri.conf.json 和发布工作流。

**示例**：

~~~powershell
git status --short
git check-ignore .tauri-updater.key src-tauri/resources/state.toml dist
~~~

**违规特征**：将签名私钥或本地状态文件加入提交，或重生密钥后仍宣称旧客户端可验证更新。

### R04: 验证覆盖受影响层

**断言**：前端改动至少运行 npm run typecheck；Rust 行为改动运行 npm run rust:test；配置、解析器或命令行为变更须增加可观察的测试。UI 改动的 PR 记录截图，不能以构建结果代替交互验收。

**示例**：

~~~powershell
npm run typecheck
npm run build
npm run rust:test
~~~

**违规特征**：只运行前端构建就宣称 Rust 持久化或 Tauri 多窗口行为已验证。
