# 核心铁律与避坑

## 适用范围

适用于图片预览、解析缓存、观察器、后台任务、更新发布和改动验证。性能基线见 D:\Image_process\luxe-tauri\docs\performance\MEMORY_RECOVERY.md。

## 规则条目

### R01: 缓存必须有预算和清理入口

**断言**：新增图片或解析缓存时，必须写清容量、淘汰条件和清理入口。跨页面清理调用 `src/ipc/memory.ts` 的 `trimMemory(true)`。

**示例**：

~~~ts
import { trimMemory } from "@/ipc/memory";

void trimMemory(true);
~~~

**违规特征**：把完整解码图片无限量放进 Map，或仅清空 React 状态却保留 Rust 缓存。

### R02: 异步结果不得覆盖新状态

**断言**：图片、文件或页面改变后，旧请求不能覆盖新状态。组件卸载后不能更新 React 状态；`ResizeObserver` 只有测量值变化时才更新状态。

**示例**：

~~~tsx
useEffect(() => {
  let active = true;
  loadState().then((state) => {
    if (active) setState(state);
  });
  return () => { active = false; };
}, []);
~~~

**违规特征**：切换图片后旧请求仍写入新图片界面，或尺寸观察器每次回调都无条件 setState。

### R03: 密钥和发布产物不得入库

**断言**：不得提交签名密钥、本地 `state.toml`、`dist/` 或 `src-tauri/target/`。修改更新签名或地址时，检查 `src-tauri/tauri.conf.json` 和发布工作流。

**示例**：

~~~powershell
git status --short
git check-ignore .tauri-updater.key src-tauri/resources/state.toml dist
~~~

**违规特征**：将签名私钥或本地状态文件加入提交，或重生密钥后仍宣称旧客户端可验证更新。

### R04: 验证覆盖受影响层

**断言**：本地 Rust 改动只对受影响文件运行 `rustfmt --check --edition 2021 <file.rs>` 等不触发编译的静态检查；禁止本地运行 `cargo build`、`cargo check`、`cargo test`、`npm run rust:test`、`npm run tauri:build` 或 `npm run tauri:dev`。本地前端改动运行 `npm run typecheck`，脚本改动运行对应 Node 22 `node:test`；前端打包、Rust 编译和测试由 `.github/workflows/ci.yml` 的 Windows x64 job 执行。配置、解析器或命令行为变更须增加可观察测试并由 CI 验证。UI 改动的 PR 记录截图，不能以构建结果代替交互验收。

**示例**：

~~~powershell
npm run typecheck
rustfmt --check --edition 2021 src-tauri/src/image_sync.rs
# 前端打包、Rust 编译与测试由 GitHub Actions 执行
~~~

**违规特征**：本地执行 Cargo/Tauri 构建或测试，或只凭前端类型检查就宣称 Rust 持久化、插件通信或桌面交互已验证。

### R05: 禁止语言索引错位

**断言**：`settings.language` 只能是 `0..=4`，依次代表 `zh_CN`、`zh_TW`、`en_US`、`ja_JP`、`tr_TR`；读取历史 TOML 时，超出范围的值必须归一化为 `0`，不得因删除旧语言而指向另一种语言。

**示例**：

~~~rust
pub fn normalize_language(index: u32) -> u32 {
    if index < 5 { index } else { 0 }
}
~~~

**违规特征**：保留旧的 16 项索引却只显示 5 项，或用数组截断让旧索引静默映射到错误语言。

### R06: 资源白名单必须闭合

**断言**：`src-tauri/resources/translations/` 中的 JSON 文件集合必须与双端语言列表完全相等；构建或测试发现旧语言资源时，检查必须失败。

**示例**：

~~~powershell
$expected = @("zh_CN.json", "zh_TW.json", "en_US.json", "ja_JP.json", "tr_TR.json")
(Get-ChildItem src-tauri/resources/translations -File -Filter *.json).Name | Sort-Object
~~~

**违规特征**：只从 Select 下拉框隐藏语言，但旧 JSON 仍随安装包发布并被 `get_all_locale_bundles` 返回。

### R07: 双向联动必须防止消息回环

**断言**：双向图片同步消息必须包含 `protocolVersion`、稳定的 `sourceInstance`、单调递增的 `sequence` 和绝对 `imagePath`；接收方对同一来源只接受大于已应用序号的消息，并将远端应用动作标记为 remote-origin，不得再次回发同一动作。

**示例**：

~~~ts
if (message.sequence <= lastSequenceBySource.get(message.sourceInstance)!) return;
lastSequenceBySource.set(message.sourceInstance, message.sequence);
applyImageSelection(message.imagePath, { origin: "remote" });
~~~

**违规特征**：两端收到对方更新后再次作为本地选择广播，或迟到的旧序号把用户刚切换的图片改回去。

### R08: 断线和路径不匹配不得破坏工作区

**断言**：收到的绝对路径未命中已扫描工作区或 `ImageEntry.jpg_path` 时，不得重置、重扫或替换其他 workspace 的目录；必须返回明确的未匹配结果并记录原因。断线重连时必须重新握手并清理已关闭会话的监听器和句柄。

**示例**：

~~~ts
const match = findImageByAbsolutePath(message.imagePath);
if (!match) return { accepted: false, reason: "image-not-indexed" };
~~~

**违规特征**：未命中时默认选择索引 0，或旧连接恢复后同时保留新旧接收器。

### R09: 传输安全与安装验证必须分开验收

**断言**：Named Pipe 必须限制为当前交互用户并验证消息长度；localhost TCP/WebSocket 必须仅绑定 loopback 并使用会话令牌；文件协议必须使用私有目录、原子替换和有界轮询。每个传输的安全检查与安装包端到端验收分别记录。

**示例**：

~~~text
Named Pipe ACL: 当前 Windows 用户 SID
TCP bind: 127.0.0.1，随机端口，随机会话令牌
文件消息: 私有目录 + 临时文件写入 + rename 原子替换
~~~

**违规特征**：TCP 监听 `0.0.0.0`、接受无长度上限的消息、共享普通可写目录作为未校验的命令通道，或用单元测试代替安装包实测。
