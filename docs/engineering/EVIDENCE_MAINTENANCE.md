# 工程证据目录用途与清理记录

## 目录用途

实际目录为 `docs/engineering/evidence/`，用于保存界面验证截图及本地分析输出。它不是应用资源目录，也不是测试夹具目录。

2026-11-15 检查了 `src/`、`src-tauri/`、`scripts/`、`plugins/`、`.github/`、Vite配置及项目入口，没有发现运行、构建或正式测试引用这些文件；引用集中在工程文档与历史经验账本。本次清理未改动产品实现或正式测试脚本，之前的未提交功能改动完整保留。

## 文档和历史记录处理

功能文档已移除全部截图链接，界面结构和行为继续通过文字与测试说明描述。ToneTool分析摘要说明辅助脚本已经删除，不能继续声称该路径有可运行脚本。

经验账本中的历史命令和截图名称保留，表示当时实际执行和生成过的材料；本次清理记录说明这些历史文件如今不再存在，历史文件名不是当前可访问链接。

全部20张截图中只有 `TONE_LCE_RESIZE_LIGHT.png` / `TONE_LCE_RESIZE_DARK.png` 已被Git跟踪，提交这次清理会记录其删除；它们仍可从历史提交提取。其他18张图片和2个辅助文件尚未跟踪或已被忽略，不能保证可以通过Git恢复。

## 后续维护

- 当前不保留截图；后续如需新增验收截图，按实际需要决定是否入库，文档只链接实际存在的文件。
- 正式回归测试继续放在 `scripts/` 或 `src-tauri/tests/` 等现有测试目录，不能让CI依赖文档截图或已忽略的本地分析文件。
- 临时浏览器夹具位于根目录 `.tmp-*`，不在本次目录清理范围内；重新执行这些夹具可能生成旧截图，运行前应检查其输出位置。
- 删除截图时同步检查Markdown链接；删除分析脚本时记录复查能力的损失，不能把“无需运行”理解为“没有任何维护价值”。

本次清理不修改应用行为、状态文件、图片/参数数据、依赖或安装包，也不会自动缩减Git历史大小。ToneMap功能改动与证据清理按不同范围分别提交，具体提交结果以Git历史为准。
